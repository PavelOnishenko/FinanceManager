# Task 3: подготовить установку из ZIP с участием разработчика

Результат задачи — готовый ZIP и [инструкция оператора](FAMILY_INSTALLATION.md).
Следом выполняются репетиция и установка другу из [общего плана](INDEPENDENT_FAMILY_DEPLOYMENT_PLAN.md).

## Выполнено

- [x] Написать инструкцию с командами PowerShell, параметризованными запросами D1, вводом секретов,
  вызовами Telegram API, ожидаемыми результатами и продолжением после прерывания.
- [x] Обновить сборщик и список файлов под [состав пилотного ZIP](FAMILY_RELEASE_BUILD.md).
  Инструкция включена в архив.
- [x] Согласовать проверки сборщика с составом пакета; выполнять их у разработчика.
  Проверка типов, шесть тестов упаковки и локальное demo миграций проходят.
- [x] Собрать настоящий Windows ZIP и проверить его после распаковки на Linux:
  состав, инструкцию, миграции, шаблон конфигурации, лицензии и Windows-зависимости.
- [x] Сверить русские release notes и инструкцию с содержимым пакета. Инструкция в ZIP работает без ссылок на файлы репозитория.
- [x] Проверить синтаксис блоков и работу вспомогательных функций в PowerShell 7 на Linux:
  заполнение конфигурации, аргументы CLI, SQL-параметры с кириллицей, проверку ответов и обработку ошибок без раскрытия токена.
  SQL из инструкции выполнен на временной SQLite со схемой проекта; команды сверены со справкой закреплённого Wrangler.

## Осталось подтвердить на Windows

- [ ] На Windows x64 выполнить офлайн-проверку встроенных инструментов из
  [части Б чек-листа упаковки](FAMILY_RELEASE_ACCEPTANCE.md#б-на-чистой-windows-x64).
- [ ] В Windows PowerShell 5.1 пройти команды инструкции в репетиции Task 4 с тестовым ботом и отдельным аккаунтом.
  Подтвердить вход, D1, миграции, настройки, deploy, secrets, webhook и двух участников.

Для этих проверок нужен оператор с Windows и доступом к тестовым аккаунтам Cloudflare и Telegram.
Локальные проверки на Linux не подтверждают запуск Windows-бинарников или установку в реальных сервисах.

## Когда задача готова

Пилотный ZIP содержит согласованный состав и проходит проверку после распаковки у разработчика.
Команды инструкции работают на поддерживаемой Windows. Внешние операции и полный путь установки
подтверждаются в репетиции Task 4; до этого её результат остаётся непроверенным.
