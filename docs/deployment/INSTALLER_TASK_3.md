# Task 3: подготовить установку из ZIP с участием разработчика

Результат задачи — одна воспроизводимая инструкция оператора на Windows x64 и, только где это необходимо,
небольшие вспомогательные команды. Следом выполняются репетиция и установка другу из
[общего плана](INDEPENDENT_FAMILY_DEPLOYMENT_PLAN.md).

## Состояние

[Инструкция установки](FAMILY_INSTALLATION.md) написана. В ней есть команды PowerShell 5.1,
параметризованные запросы D1, ввод секретов, вызовы Telegram API, ожидаемые результаты и продолжение после прерывания.
Также описано, что сохранить владельцу и как восстановить конфигурацию при потере файлов.
Полный проход на Windows с Cloudflare и Telegram ещё не выполнен; он относится к репетиции Task 4.

## Оставшаяся работа

- [ ] Проверить на Windows пути, синтаксис и обработку ошибок команд из инструкции, используя
  [проверенные операции Task 1](INSTALLER_TOOLCHAIN_PROOF.md) и встроенные инструменты ZIP.
- [ ] Привести сборщик и список файлов к [составу пилотного ZIP](FAMILY_RELEASE_BUILD.md), включая `FAMILY_INSTALLATION.md`.
- [ ] Согласовать проверки сборщика с новым составом. Проверки состава, шаблона и миграций выполнять у разработчика.
- [ ] Проверить итоговый архив после распаковки по [чек-листу упаковки](FAMILY_RELEASE_ACCEPTANCE.md).
- [ ] Сверить русские release notes и инструкцию с составом пакета и проверенными командами.

## Когда задача готова

Пилотный ZIP содержит только файлы из согласованного состава и проходит проверку после распаковки у разработчика.
Инструкция содержит один полный путь установки и короткие действия при описанных сбоях.
Оператору не нужно искать команды по переписке или придумывать SQL на сеансе с другом.
В ней явно отмечено, что проверено локально и что ещё предстоит подтвердить на Windows с реальными сервисами в Task 4.
