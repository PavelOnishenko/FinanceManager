# Семейный финансовый бот — релиз 1 (предварительная сборка)

Это техническая сборка для проверки упаковки. Мастер установки, подключение
Cloudflare и Telegram, установка и обновление пока не реализованы (задачи 3–6).
Не передавайте этот архив семье для ведения финансов.

В архиве находятся готовый Worker, миграции, Node.js и Wrangler для Windows x64.
После распаковки запустите `Start setup.cmd`: он проверит комплектность архива
и сообщит о текущем ограничении. Интернет для этой проверки не нужен.
Сборка ничего не создаёт в Cloudflare и не обращается к Telegram.

Планируемый пилот не включает резервное копирование, восстановление и откат.
Возможна потеря данных. Полные инструкции появятся вместе с работающим мастером.
