# Семейный финансовый бот — релиз 1

В архиве находятся готовый Worker, миграции, Node.js и Wrangler для Windows x64.
Выберите одну полную инструкцию и выполняйте команды PowerShell по порядку:

- `FAMILY_INSTALLATION.md` — установка на компьютере друга в его Cloudflare-аккаунте с помощью разработчика.
- `FAMILY_INSTALLATION_DEVELOPER_ACCOUNT.md` — установка на компьютере разработчика в его Cloudflare-аккаунте.
  Для друга нужны только Telegram и подтверждение настроек и участников; разработчик имеет административный доступ к D1.

Каждой семье нужны отдельные Worker, D1 и Telegram-бот. Исходный ZIP универсален и не содержит данных установки или секретов.
После настройки бот работает при выключенном компьютере. Предыдущая установка по первой инструкции завершена;
новый сценарий проверяется отдельно, подготовка ZIP не подтверждает живую установку.

Обновления проводит разработчик по инструкции для перехода с установленного релиза.
Перед изменениями он сохраняет экспорт целевой D1 вне Git и каталога ZIP, проверяет ресурсы и результат обновления.
Перед изменением схемы разработчик проверяет восстановление на тестовой базе:
проверка файла экспорта сама по себе не доказывает возможность восстановления.
