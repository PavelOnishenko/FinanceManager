# Семейный финансовый бот — релиз 1 (предварительная сборка)

В архиве находятся готовый Worker, миграции, Node.js и Wrangler для Windows x64.
Пилот рассчитан на одного друга: разработчик выполняет установку на его компьютере
через AnyDesk или TeamViewer по инструкции оператора. Друг владеет Telegram-ботом,
аккаунтом Cloudflare и данными. После настройки компьютер можно выключить.

Полная ручная установка из ZIP ещё требует инструкции и репетиции. До их завершения
эта сборка предназначена для проверки пакета, а не для начала ведения семейных финансов.

Обновления проводятся в отдельном совместном сеансе. Перед изменениями оператор
сохраняет экспорт D1 у владельца, проверяет целевые ресурсы и затем результат обновления.
Перед изменением схемы разработчик проверяет восстановление на тестовой базе:
проверка файла экспорта сама по себе не доказывает возможность восстановления.
